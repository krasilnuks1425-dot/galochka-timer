# Відпочинок між підходами

Таймер паузи між сетами в залі. Працює в браузері, зручно на телефоні.

## Як запустити

Відкрий `index.html` у браузері (подвійний клік або перетягни файл у Chrome / Edge).

Або з PowerShell у папці проєкту:

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Потім відкрий http://127.0.0.1:8765/

На телефоні: відкрий той самий файл, або надішли його собі і відкрий у Safari / Chrome. Додай на домашній екран — великі кнопки, екран не засинає під час відліку.

## Як користуватись

1. Зроби підхід.
2. Обери час (30 с … 3 хв) або підкрути ±15 с.
3. Натисни **Старт**.
4. Коли час вийде — сигнал і вібрація, лічильник підходу збільшиться.
5. **Ще раз** — наступна пауза з тим самим часом.

Останню тривалість додаток запам’ятовує.

## Файли

- `index.html` — розмітка
- `css/styles.css` — вигляд
- `js/app.js` — таймер, звук, вібрація, wake lock
